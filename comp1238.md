## Week 1 - History
- One writing system can be used by many languages.
- Cuneiform looks weird.
- The Epic of Gilgamesh was epic.

## Week 2 - Bits and Bytes
- Computers store information using bits and bytes.
- A bit is a binary digit: 0 or 1.
- A byte contains 8 bits.
- Binary is a number system that uses 0 and 1.

## Week 3 - Computer Memory
- RAM is volatile memory.
- Storage keeps data when the computer is turned off.
- ASCII represents characters using numeric codes.

## Week 4 - Markdown and Text Files
- Markdown uses headings, lists, links, and code blocks.
- README files explain projects.
- Links and images can be added using Markdown syntax.

## Week 5 - Command Line
- The terminal allows users to enter commands.
- `ls` lists files and directories.
- `cd` changes the current directory.
- `cat` displays file contents.
- `man` displays command manuals.
